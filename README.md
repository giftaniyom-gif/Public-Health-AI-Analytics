# Public-Health-AI-Analytics
"AI-driven epidemiological research and data triangulation models"
Technical Portfolio: Public Health Informatics and Outbreak Response

AI-Enhanced Public Health Operational Framework

This repository serves as a technical blueprint for integrating artificial intelligence into public health organizational workflows. Utilizing advanced PoliSync frameworks, the project features standardized governance frameworks and prompt engineering workflows designed to modernize administrative planning and research synthesis. It establishes a modernized logic for leveraging AI to accelerate evidence-based decision-making and scale the reach of public health advocacy through automated storytelling.

Technical Skills: Prompt engineering workflows, AI for research and data insights, AI-powered storytelling, and governance frameworks for AI implementation.

Public Health Impact: Streamlining complex administrative planning, enhancing advocacy reach through AI-generated content, and significantly improving the speed of health data synthesis for rapid response.

IA2030 Data Strategy & Action Framework Development

This repository documents the technical assets of the WHO IA2030 Data Strategy & Use Working Group. It features an ecosystem-wide DSUWG work plan designed to align global funding cycles with country-level implementation. The framework establishes the technical requirements for a "fit-for-purpose" data ecosystem, ensuring cross-priority data integration to track global immunization goals.

Technical Skills: Data-guided delivery strategy, ecosystem-wide DSUWG work planning, and cross-priority data integration.

Public Health Impact: Enabling high-quality, fit-for-purpose data usage to inform global immunization performance and scaling up best practices across participating countries to meet IA2030 strategic priorities.

GIS-Based Settlement Digitization for Polio Eradication

This repository contains the geospatial intelligence and digitization logic developed for the WHO Horn of Africa Mapathon. Documentation focuses on the processing of high-resolution satellite imagery to identify building points and structures in insecure regions. This geospatial framework provides the foundational data required for digital micro-planning in areas previously considered "blank spots" on health maps.

Technical Skills: GIS mapping, building-point identification, high-resolution satellite imagery analysis, and digital micro-planning.

Public Health Impact: Facilitating precision vaccination campaigns in insecure and hard-to-reach areas across the Middle East and Horn of Africa (Kenya, Somalia, and Ethiopia) to support the Global Polio Eradication Initiative.

SORMAS Integrated Community-Based Surveillance

This repository provides the documentation and implementation logic for a COVID-19 surveillance system utilizing the SORMAS platform. It features technical configurations for both event-based and indicator-based surveillance, with a specific focus on ALERT and ACTION threshold triggers. The repository details the optimization of contact tracing algorithms to manage public health incidents in high-risk regions.

Technical Skills: SORMAS data analysis, contact tracing algorithm optimization, threshold/trigger configuration, and event-based surveillance strengthening.

Public Health Impact: Early detection and verification of public health incidents through optimized community-based surveillance, facilitating rapid response and transmission reduction in high-risk zones.

Data Triangulation for Immunization Coverage Improvement

This project repository focuses on the synthesis of disparate data sources to identify systemic gaps in health service delivery. It outlines a framework for integrating DHIS 2.0, Epi-info, and statistical software to conduct rigorous Root Cause Analysis (RCA) of immunization outbreaks. The logic emphasizes data-driven identification of immunity gaps to refine routine immunization performance.

Technical Skills: Data triangulation, STATA/SPSS analysis, Epi-info, and DHIS 2.0 integration.

Public Health Impact: Identifying immunity gaps and performing Root Cause Analysis (RCA) to reduce health inequities and improve the performance of routine immunization systems across member states.

African Union Continental Immunization Strategy (CIS) Management

This repository reflects the strategic management framework for the Continental Immunization Strategy (CIS) covering 55 AU Member States. It features documentation for the oversight of complex grant portfolios and the strategic situation analysis required for continental health preparedness. The framework coordinates priorities across technical teams and multilateral donors to align vaccination execution.

Technical Skills: Multilateral grant portfolio management (GAVI, UNICEF, World Bank), performance tracking, and strategic situation analysis.

Public Health Impact: Accelerating Mpox vaccination coverage and building regional preparedness for vaccine-preventable diseases (VPDs) across 55 countries through coordinated continental action.

Yellow Fever Reactive Vaccination Coordination (GOARN)

This repository documents the technical coordination of international emergency vaccine requests utilizing the OSCAR tool and standardized WHO templates. It features the review logic for epidemiological and entomological investigation reports used to facilitate ICG approvals. The documentation highlights the use of vulnerability risk mapping to prioritize reactive vaccination campaigns in the Lake Chad Basin.

Technical Skills: OSCAR tool utilization, ICG request facilitation, epidemiological/entomological report review, and vulnerability risk mapping.

Public Health Impact: Coordinating international emergency vaccine requests and strengthening national capacities for early outbreak detection and rapid response via evidence-based interventions.

Integrated Supplementary Immunization Activities (SIA) Analytics

This project repository contains the methodology and analytics logic for real-time SIA monitoring in high-risk Local Government Areas (LGAs). It leverages DHIS 2.0 and LQAS surveying conducted by independent monitors to implement the Gavi Zero Dose strategy. The repository focuses on improving data completeness and reach for underserved populations through systematic feedback loops and evidence-based planning.

Technical Skills: DHIS 2.0 real-time SIA monitoring, LQAS surveying, Independent monitoring, and Gavi Zero Dose strategy implementation.

Public Health Impact: Improving the quality and timeliness of immunization data while reaching "zero-dose" children in high-risk LGAs and ensuring the continuity of essential care.
